# Robot-SImu

브라우저만으로 도는 학습용 로봇 실험실. 설치할 것이 없고 인터넷 없이 실행된다.

실험을 골라 한 틱 안에서 **감지 → 판단 → 행동 → 적분**이 어떻게 이어지는지 멈추고, 한 칸씩 돌리고, 값을 바꿔 보며 확인한다.

## 실험

| 실험 | 다루는 것 | 바꿔 볼 값 |
|---|---|---|
| 주행 로봇 | LiDAR, A* 경로 계획, 주행 기록 오차, 마찰과 미끄러짐 | 물리 모드, 질량, 마찰 계수, 센서 노이즈 |
| 매니퓰레이터 | 정·역기구학, PD 제어, 중력 보상, 토크 한계, 집어 옮기기 | 제어 강성, 감쇠비, 중력 보상, 토크 한계, 짐 무게, 엔코더 노이즈 |
| 진자 | 적분 방식과 DT에 따른 에너지 오차 | 적분 방식, 시작 각도, 줄 길이, 마찰 |

## 실행

`index.html`을 브라우저로 연다. 시작 화면에서 사양(최소 / 최고)을 고른다.

서버로 열고 싶으면:

```bash
py -m http.server 8770 --bind 127.0.0.1
```

주소 뒤에 붙일 수 있는 값: `?q=low` 또는 `?q=high`(시작 화면 건너뛰기), `?exp=rover|arm|pendulum`(실험 바로 열기), `?seed=숫자`(난수 시드).

## 조작

| 조작 | 동작 |
|---|---|
| 드래그 / 휠 | 카메라 회전 / 확대 |
| 한 틱 실행 | 일시정지하고 정확히 한 틱만 진행 |
| 주행 로봇: 바닥 클릭, W A S D | 목표 지정, 수동 조종 |
| 매니퓰레이터: 블록 클릭, 빈 곳 클릭 | 집기, 이동 또는 내려놓기 |

각 실험의 "해 볼 실험" 목록이 화면 오른쪽에 나온다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 공용 도구, 고정 스텝 루프, 화면, 조작 패널 |
| `exp/rover.js`, `exp/arm.js`, `exp/pendulum.js` | 실험 하나씩. 계산(`step`)과 그림(`init`, `draw`)이 나뉘어 있다 |
| `vendor/three/` | Three.js 0.160.0 (MIT) |

사양 선택은 화면 품질만 바꾸고 계산은 같다.

### 실험 추가하기

`exp/` 에 파일을 만들고 `EXPS.push({...})`로 등록한 뒤 `index.html`에 `<script src="exp/이름.js">` 한 줄을 넣는다. 필요한 항목은 `exp/pendulum.js`가 가장 짧은 예시다: `id`, `name`, `hint`, `cam`, `graph`, `params`, `labs`, `init`, `reset`, `step`, `draw`, `sample`, `stages`, `stat`, `test`.

콘솔에서 `sim.use('arm'); sim.run(1000)`으로 화면 없이 1000틱을 돌릴 수 있다.
