# Robot-SImu

브라우저만으로 도는 학습용 로봇 시뮬레이터. 설치할 것이 없고 인터넷 없이 실행된다.

한 틱 안에서 **감지 → 판단 → 행동 → 적분**이 어떻게 이어지는지 멈추고, 한 칸씩 돌리고, 값을 바꿔 보며 확인한다.

## 실행

`index.html`을 브라우저로 연다. 시작 화면에서 사양(최소 / 최고)을 고른다.

서버로 열고 싶으면:

```bash
py -m http.server 8770 --bind 127.0.0.1
```

주소 뒤에 `?q=low` 또는 `?q=high`를 붙이면 시작 화면을 건너뛴다. `?seed=숫자`로 난수 시드를 바꾼다.

## 조작

| 조작 | 동작 |
|---|---|
| 바닥 클릭 | 목표 지정 |
| 드래그 / 휠 | 카메라 회전 / 확대 |
| W A S D, 방향키 | 수동 조종 (누르는 동안) |
| 한 틱 실행 | 일시정지하고 정확히 한 틱만 진행 |

## 해 볼 실험

1. 일시정지 후 **한 틱 실행**을 눌러 네 단계의 값이 바뀌는 순서를 본다.
2. 동역학 + 명시적 오일러 + 질량 1 kg + DT 1/10초: 속도 그래프가 진동한다. 암시적 오일러로 바꾸면 멈춘다.
3. 동역학 + μ 0.05: 가속·제동이 늦고 회전에서 옆으로 미끄러진다.
4. 주행 기록 오차를 올리면 빨간 테두리(로봇이 믿는 위치)가 실제와 벌어진다. 노란 원 안에 들어오면 보정된다.

## 구조

`index.html` 한 파일이다. 앞부분 "1. 시뮬레이션"은 화면과 무관한 계산이고, "2. 화면"은 상태를 읽어 그리기만 한다. 사양 선택은 화면 품질만 바꾼다.

콘솔에서 `sim.run(1000)`으로 화면 없이 1000틱을 돌릴 수 있다.
